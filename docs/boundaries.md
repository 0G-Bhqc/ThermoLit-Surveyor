# 适用边界与定位(Boundaries & Positioning)

> 本文回答三个问题:这个智能体**能用在哪些科研领域**、**相对现有科研智能体框架独特在哪**、
> **真实可靠性到底如何**。全部结论附真实运行证据,并明确标注"已验证"与"未验证"。
> 边界文档本身是框架的一部分:接入新领域前,请先对照本文的硬条件清单。

## 一、一句话定位

一个"**只允许程序产生数字**"的领域文献调研智能体框架:检索 → 确定性领域审计 →
可回验假说 → 实验方案设计 → 实验结果程序化回验。
它不与"自动做实验/写论文"的框架竞争,而是补它们共同缺失的一层:**文献数值的可信性**。

## 二、维度一:科研领域边界(核心)

一个科研领域能否接入本框架,有三个**硬条件**(全部满足才可):

1. **参数可解析**:核心观测量能写成"数字 + 单位"的字符串,且单位体系明确(可解析为 SI);
2. **存在可写成纯函数的领域校验关系**:至少一条能编码为代码的物理/化学约束
   (如 Wiedemann-Franz 定律、S-Q 极限、Nernst 关系),用于派生计算与一致性体检;
3. **文献数值密集**:该领域的实验论文以报告测量值为主要产出(而非纯理论/纯定性)。

按此标准的领域清单:

| 领域 | 量化参数 | 可编码的校验关系 | 现状 |
|---|---|---|---|
| **热电材料输运** | S、σ、κ、zT、载流子浓度 | Wiedemann-Franz 解耦、zT=S²σT/κ、非晶下限 | ✅ 首个 profile,已真实校准 |
| 超导材料 | Tc、上临界场 | McMillan/DED 型 Tc 关系、Pauli 极限 | 🟡 框架就绪,待写 profile(M3 首选候选) |
| 锂离子电池 | 容量、库仑效率、衰减率 | 库仑效率-衰减恒等、SEI 模型约束 | 🟡 同上 |
| 多相催化 | TOF、转化率、选择性 | 阿伦尼乌斯一致性、选择性恒等式 | 🟡 同上 |
| 半导体迁移率 | μ、n | Matthiessen 定则、Hall 关系 | 🟡 同上 |
| 光伏 | PCE、Voc、Jsc | Shockley-Queuer 极限比对 | 🟡 同上 |
| 合金/结构材料 | 强度、硬度 | Hall-Petch 关系 | 🟠 引擎较复杂,候选 |
| 药物活性 | IC50/Ki | 定量构效关系(统计性,非严格物理约束) | 🟠 校验关系偏统计,审计强度受限 |
| 纯理论 / 数学 | — | — | ❌ 无可解析数值参数 |
| 纯定性研究(社会学等) | — | — | ❌ 不满足硬条件 1/3 |

> 接入新领域 = 写一个 `DomainProfile`(抽取 schema + 审计纯函数 + 审计表 + 缺口提示),
> 编排层零改动;流程见 [CONTRIBUTING](https://github.com/0G-Bhqc/ThermoLit-Surveyor/blob/main/CONTRIBUTING.md)。
> 判断一个领域是否值得接入的最快方法:随机抽 10 篇该领域论文摘要,数一数带单位的数值出现率。

## 三、维度二:任务类型边界

**✅ 适用的任务:**
- 证据整理:某材料/体系的参数矩阵(谁测的、什么条件、什么值,带 DOI);
- 数值体检:报道值与物理约束的一致性(zT 偏差、κ_l 正负、跨温混计);
- 缺口分析:哪些参数缺失、哪些文献值需要复核;
- 可证伪假说生成与实验方案设计(判据为规范变量+阈值,可程序化回验);
- 实验结果回流后的假说状态判定(supported/refuted/inconclusive)。

**❌ 不适用的任务:**
- 系统性综述(PRISMA 级):无引用网络 snowballing、无全量检索承诺——
  产出是**证据样本,不是文献全集**;
- 实验执行、仿真计算、可投稿论文写作(AI Scientist / Robin 的领地);
- 理论证明、机理发现;
- 只需要"读一篇 PDF 并问答"的场景(paper-qa 类工具更轻量)。

## 四、维度三:证据类型边界

- **段落级证据**:进入管线的是检索返回的摘要/全文片段,不是整篇论文——
  片段里没有的数值它看不见(这是"诚实"而不是缺陷,但构成覆盖度边界);
- **语言**:抽取 schema 为英文(英文文献为主),报告输出为中文;
- **语料依赖**:检索面 = Sciverse 语料(2500 万+ 全文段落)∩ 查询质量;
- **数值产出率**:真实 A/B 中 44%→62% 的记录含可解析数值(单次对比,方向性证据)——
  综述性/应用性段落会被检索预筛降权,但无法保证每条记录都带数字。

## 五、维度四:可靠性边界(诚实版)

**已验证(有真实运行证据):**
- 抄写忠实性 5/5:五个抽取数值全部逐字出自其来源段落(PbTe 真实调研);
- 来源真实性 5/5:四个已有 DOI + 一个 Crossref 新解析 DOI 全部确认为真实论文;
- 防线有效性:真实运行中 4 条字段级编造引用被包含校验点名;温度混计时
  **拒绝给出偏差百分比**(宁可"无法判定",不说错的话);
- 工程:107 个离线测试(CI 无密钥全绿)、打包/文档/API/断点续跑完整。

**方向性(单次真实 A/B,非统计结论):**
- 含数值记录率 44%(4/9)→ 62%(5/8);金标评测(节选级真值)召回率 1.0、误差 0、
  编造率 0——样本小(n=5 数值真值),且为同模型一致性测试,泛化准确率待扩充金标。

**未验证:**
- 跨领域泛化(单 profile);假说的领域专家质量;相对领域全文献的检索召回率;
- 与基线框架的受控对比实验。

**已知失效模式(真实发生过,均有对应防护):**
LLM 端点瞬时故障(重试+顶层兜底)、标题相似度低于阈值拿不到 DOI(2/9,诚实保留 N/A)、
MathML 污染标题(已修)、同文献不同段落重复(已修)、Crossref 近似错配(阈值拒绝)。

## 六、相对现有科研智能体框架的独特之处

| 框架 | 定位 | 数值如何产生 | 与本项目差异本质 |
|---|---|---|---|
| [Agent Laboratory](https://github.com/SamuelSchmidgall/AgentLaboratory)(JHU/AMD) | 端到端 ML 研究:想法→实验→论文+代码 | LLM 生成代码跑实验 | 自动化"做研究";无领域物理校验层 |
| [The AI Scientist](https://alphaxiv.org/abs/2501.04227)(Sakana) | 全自动论文生成+自动审稿 | LLM 生成 | 范围广而审计弱,数值可信性依赖 LLM 自觉 |
| [Robin](https://www.nature.com/articles/s41586-026-10652-y)(Nature 2026) | 湿实验发现闭环 | 实验数据 | 闭环在"实验台";本项目闭环在"文献证据",互补 |
| paper-qa(FutureHouse) | 文献问答/引用 | 摘录原文 | 最接近的组件;无缺口驱动检索、无物理审计、无假说回验 |
| 通用 DeepResearch 类 | 网页调研报告 | LLM 自由生成 | 无确定性校验,数值幻觉不可检 |

**可辩护的三个差异点:**
1. **确定性领域审计层**——神经符号方法在文献场景的落地:LLM 只抄写带单位的字符串,
   一切换算与派生由有单元测试的纯函数完成;
2. **解析器驱动的缺口闭环**——Pass 2 检索方向由"哪些字段解析失败"的确定性产物决定;
3. **假说是可执行对象**——判据=规范 SI 变量+阈值+温度条件,由代码归一与回验。

## 七、真实案例(全部可复核)

1. **抓到真实幻觉**:PbTe 真实调研中,AI 为 4 个字段提供了"看起来像原文"的引用句,
   包含校验判定摘录并非真实存在于原文,全部点名"证据句未核实"。
2. **拒绝误导性计算**:某文献报道 zT=1.4@750K 而 S/σ/κ 为 300K 值——引擎输出
   "zT报道温度与计算温度不一致,未做偏差判定",而非看似精确的"偏差 48%"。
3. **DOI 锚点全链路**:9 篇真实文献,Sciverse 命中不含 DOI → Crossref 标题解析
   (相似度≥0.6)补齐 7 个,全部通过 doi.org 注册库核验;2 个低于阈值被诚实拒绝。
4. **数值密度预筛 A/B**:同 query 同 top_k,含数值记录率 44%→62%。
5. **校准即可靠性**:首轮真实调研暴露 4 个离线测试测不出的缺陷(async 协程、
   无 DOI 字段、MathML 标题、记录重复),全部修复并有回归测试——
   "可靠"是被真实世界锤出来的,不是宣称出来的。

## 八、何时该用 / 不该用(决策清单)

用,如果:领域满足硬条件 1-3;你需要的是"带 DOI 的参数证据 + 数值体检 + 可回验假说";
你接受段落级证据覆盖度;你有 LLM 端点与检索源 token。

不用,如果:你需要系统全量综述;你的领域没有可编码的校验关系;你要的是端到端
自动化实验与论文(AI Scientist / Agent Laboratory 更合适);你要求每个数字都有
全文级保证(当前只有段落级)。
